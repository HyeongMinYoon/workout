# 세트 · 헬스 기록

헬스장에서 운동 중에 쓰는 개인용 웨이트 트레이닝 기록 앱. 정적 파일 하나로 도는 PWA다.

- 5일 분할 루틴을 62개 종목 라이브러리에서 자동 편성한다
- 지난 기록을 보고 다음 세트 무게를 처방한다 (증량 / 유지 / 디로드)
- 부위별 주간 볼륨을 목표 구간과 비교한다
- 갤럭시 Z 폴드 7 커버 화면(412 × 940) 세로, 한 손 조작, 다크 모드 고정

## 실행

빌드 도구도 의존성도 없다. 아무 정적 서버로 열면 된다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://` 로 직접 열면 화면은 뜨지만 브라우저가 `localStorage`를 막는 경우가 있어 기록이 안 남을 수 있고,
서비스 워커(오프라인 캐시)도 등록되지 않는다. 실제로 쓸 때는 http(s)로 열어라.

### 폰에 설치

GitHub Pages 같은 https 호스팅에 올린 뒤 브라우저의 "홈 화면에 추가"를 쓰면
주소 표시줄 없는 standalone 앱으로 뜬다. 헬스장은 지하가 많아 서비스 워커가 셸을 캐시해 둔다.

앱 본체는 **네트워크 우선**이라 새로 배포한 버전이 다음 실행에 바로 뜬다.
회선이 느리거나 끊겼으면 2.5초 뒤 캐시로 넘어가므로 지하에서도 즉시 열린다.

## 파일

```
index.html              앱 전체 — 마크업 · CSS · 로직
manifest.webmanifest    PWA 매니페스트
sw.js                   서비스 워커 (앱 본체는 네트워크 우선, 나머지는 캐시 우선)
icon.svg, icon-*.png    아이콘
docs/design-brief.md    UI 리파인 브리프 (요구사항 원문)
docs/design-decisions.md 무엇을 왜 바꿨는지
```

## 데이터

기록은 브라우저 `localStorage`에 남는다. 서버도 계정도 없다.

| 키 | 내용 |
|---|---|
| `gym5:sessions` | 세션 배열 — 날짜 · Day · 종목별 세트 `{무게, 횟수, 완료}` (최근 300개) |
| `gym5:excl` | 추천에서 제외한 종목 이름 배열 |
| `gym5:rests` | 종목별로 기억된 휴식 시간(초) |
| `gym5:gears` | 종목별로 등록한 기구 이름 목록 |
| `gym5:bw` | 체중 (새 종목 첫 무게 추정에만 사용) |

세션의 `sw` 필드에 종목 대체가 슬롯 번호로, `gear` 에 종목별 기구가, `wl` 에 준비운동 유산소 레벨이 들어간다.
대체는 프로그램 자체를 바꾸지 않지만, **그 Day 를 마지막으로 연 날의 선택을 물려받는다**.

기록은 **종목 이름**으로 저장된다. 루틴이 다시 짜여도, 종목을 껐다 켜도 이전 기록과 증량 이력이 이어진다.

### 백업

브라우저 데이터를 지우거나 폰을 바꾸면 기록이 그대로 사라진다. 처방은 과거 기록에서 나오므로
잃으면 앱이 처음으로 돌아간다. **목록 탭 하단 → 데이터**에서 파일로 빼고 넣을 수 있다.

- **내보내기** — `workout-YYYY-MM-DD.json` 로 저장. 세션 전체와 제외 목록이 들어간다
- **가져오기** — 같은 `날짜 + Day`는 가져온 것으로 덮어쓰고 나머지는 합친다.
  같은 파일을 두 번 넣어도 중복되지 않으므로, 폰 두 대를 오갈 때도 그대로 쓸 수 있다

## 구조

세로 flex 3단 고정. 헤더와 하단 독은 고정, 가운데만 스크롤한다.
상태가 바뀌면 `render()`가 `innerHTML`을 통째로 갈아끼우므로, 진입 애니메이션 없이
CSS transition 수준의 마이크로 인터랙션만 쓴다.

탭은 네 개다.

- **오늘** — 그날 세션. 진행 중인 종목 하나만 펼치고, 끝난 것은 한 줄로 접는다.
  앱을 열면 **마지막으로 기록한 Day의 다음 Day**가 뜬다(Day 5 다음은 Day 1). 며칠을 쉬었든
  프로그램 순서대로 이어지고, 오늘 이미 기록한 게 있으면 그 Day를 이어서 연다.
  다른 날을 하고 싶으면 상단 세그먼트로 바꾸면 된다.
  기구가 고장났거나 남이 쓰고 있으면 **교체**로 같은 부위의 다른 종목으로 갈아탄다.
  한 번 바꾸면 다음 사이클의 같은 Day 가 그 선택을 물려받으므로, 늘 같은 종목으로 바꾸던 슬롯은
  더 안 눌러도 된다. `되돌리기`를 누르면 기본 종목으로 고정된다.
  보강 슬롯은 부위를 안 가리므로 교체가 순환 대신 **부위별 목록**을 연다.
  `행잉 니레이즈` 같은 맨몸 종목은 무게 칸 없이 **횟수만** 받는다.
  세트 값을 누르면 **키패드**로 직접 입력한다 — 덤벨 랙에 없는 무게나 제각각인 케이블 눈금은 ± 단위로 안 맞는다.
  수정 창의 `저장`은 값만 남기고, `저장하고 휴식`은 기록 · 체크 · 휴식을 한 번에 한다 —
  휴식 중에 다음 세트를 미리 손볼 때 타이머가 리셋되지 않는다
- **진행** — 최근 7일 부위별 볼륨을 목표 눈금선과 비교
- **기록** — 8주 부위별 볼륨 추이, **종목별 추정 1RM 추이**(최근 8세션), 세션 로그.
  부위 볼륨은 종목을 바꾸면 흔들리지만(딥스를 빼면 가슴이 −42%로 뜬다) 종목별 1RM은 안 흔들린다.
  기구 라벨이 다르면 무게 축이 다르므로 줄을 나눈다.
  세션 로그에는 **소요 시간**과 그날 한 순서가 그대로 남는다
- **목록** — 67개 종목 라이브러리. 끄면 그 종목이 추천에서 빠지고 루틴이 다시 짜인다

제외가 많아 한 부위의 후보가 슬롯 수보다 적으면, 그 부위를 **주로 다루는 날이 먼저** 가져간다.
밀린 슬롯은 템플릿에 적힌 대체 부위에서 채우고(Day 2 의 둔근 슬롯 → 대퇴사두), 거기도 비면
그때야 같은 종목을 두 날에 쓴다 — 종아리처럼 기구가 하나뿐인 부위가 그렇다.

하루 종목 수가 6개(컨디셔닝 제외)에 못 미치면 **어깨 · 후면삼각 · 이두 · 삼두 · 복근에서 보강을 최대 2개까지**
끼워 넣는다.
고를 때는 주간 처방 세트가 가장 적은 부위부터 가져오므로, 이미 많이 하는 부위에는 안 붙는다.
보강 종목은 메타 줄에 `보강`으로 표시된다.

## 처방 규칙

목표는 근비대 + 체지방(리컴프) 고정이다.

- 컴파운드 4세트 6–10회 / 휴식 120초, 고립 3세트 10–15회 / 휴식 60초.
  휴식은 유형별 기본값일 뿐이고, 휴식 캡슐에서 ±30 으로 조절하면 **그 종목의 시간으로 기억**한다.
  감량 세트가 붙은 종목은 회복이 모자랐다는 뜻이므로 **자동으로 +30초**가 붙는다(손으로 조절하면 그 값이 이긴다)
- 처음 하는 종목은 **같은 부위 · 같은 유형에서 이미 하고 있는 종목의 기록**을 계수 비로
  환산해 첫 무게를 잡는다. 헬스장 케이블 눈금이 표와 달라도 사람 기준으로는 맞는다.
  덤벨과 케이블이 섞이면 값이 크게 벌어지므로 평균이 아니라 중앙값을 쓴다.
  참고할 기록이 없으면 **체중 × 종목별 계수**로 떨어진다(목록 탭에 체중 입력 시).
  한 번 기록되면 그다음부터는 그 종목의 실제 기록으로 처방한다
- **덤벨 종목은 랙에 있는 무게로만 처방한다.** 증량 단위로 계산하면 6.25kg 덤벨이 나온다.
  칸 폭도 무게대마다 다르다 — 8 다음은 9 지만 20 다음은 22 다. 기본 눈금에
  **직접 기록한 무게를 합쳐** 랙을 만들므로, 그 헬스장에만 있는 12.5kg 도 한 번 쓰면 칸이 된다.
  수정 창의 ± 도 같은 칸을 밟는다
- 마지막 세션에서 **모든 워킹 세트가 목표 상한을 채웠으면** 증량 단위만큼 올린다.
  워킹 세트 정족수는 `세트수 − 1`이라 램프업 한 세트는 증량을 막지 않는다
- 반복이 목표 상한을 **3회 이상 넘겼으면** 증량 단위로 기어가지 않고,
  추정 1RM을 유지한 채 목표 상한에 맞는 무게로 한 번에 옮긴다
- 마지막 세션에서 **최고 중량 세트가 목표 하한 아래로 무너졌으면**(60kg × 13, 13, 6)
  무너진 수만큼 **뒷세트를 −10%로 내린다**(지난번에 직접 더 내렸으면 그 폭을 따른다). 앞 세트에는 맞는 무게이므로 무게를 낮추는 대신
  뒷세트만 채우게 하는 것이다. 한 번 붙은 감량 구조는 증량할 때도 같이 따라 올라간다.
  뒷세트를 손으로 최고 중량에 맞춰 채우면 다음 세션에 사라진다
- 증량 판정은 **최고 중량 세트만** 본다. 무게가 다른 세트의 반복은 비교 대상이 아니다
- 3세션 연속 최고 볼륨을 못 넘기면 **최고 시점 무게의 −10%로 디로드**
- 그 외에는 무게 유지, 목표 횟수 +1.
  단 **최고 중량으로 세트를 못 채웠으면 횟수를 안 올린다** — 한 세트만 올리고 무너진 날의
  그 한 세트를 기준으로 +1 하면 못 채운 무게에 더 많은 횟수를 요구하게 된다
- 그 종목을 **2일 안에 했으면** 메타 줄에 `어제도 한 종목`으로 알린다.
  교체하다 보면 같은 종목이 두 Day 에 걸려 하루 걸러 두 번 하게 되는데, 처방은 앞뒤 날짜를 못 본다

주간 볼륨 목표는 두 단계다. 기록이 4주 미만이면 프로그램이 처방한 볼륨의 95~110%,
4주가 쌓이면 같은 부위 직전 4주 평균에서 +N%가 목표 구간이 되고 훈련 주차가 늘수록 좁아진다.
부위 집계는 주동근 1.0배, 컴파운드의 보조근(벤치 → 삼두·어깨)은 0.5배로 잡는다.

### 기구

같은 종목이라도 기구가 다르면 무게 축이 다르다. 테크노짐 50kg 과 다른 브랜드 50kg, 가벼운 케이블 25 와
무거운 케이블 25 는 다른 부하다. 그래서 종목 카드 헤더의 **기구 칩**으로 라벨을 달면
**증량 이력이 기구별로 나뉜다**. 라벨을 안 달면 종전처럼 하나로 합쳐진다.
한 번 고르면 다음 세션이 그 기구를 물려받는다.
