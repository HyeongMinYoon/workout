# 세트 · 헬스 기록

헬스장에서 운동 중에 쓰는 개인용 웨이트 트레이닝 기록 앱. 정적 파일 하나로 도는 PWA다.

- 5일 분할 루틴을 62개 종목 라이브러리에서 자동 편성한다
- 지난 기록을 보고 다음 세트 무게를 처방한다 (증량 / 유지 / 디로드)
- 부위별 주간 볼륨을 목표 구간과 비교한다
- 갤럭시 Z 폴드 7 커버 화면(412 × 940) 세로, 한 손 조작, 다크 모드 고정

## 실행

빌드 도구도 의존성도 없다. 아무 정적 서버로 열면 된다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://` 로 직접 열면 화면은 뜨지만 브라우저가 `localStorage`를 막는 경우가 있어 기록이 안 남을 수 있고,
서비스 워커(오프라인 캐시)도 등록되지 않는다. 실제로 쓸 때는 http(s)로 열어라.

### 폰에 설치

GitHub Pages 같은 https 호스팅에 올린 뒤 브라우저의 "홈 화면에 추가"를 쓰면
주소 표시줄 없는 standalone 앱으로 뜬다. 헬스장은 지하가 많아 서비스 워커가 셸을 캐시해 둔다.

## 파일

```
index.html              앱 전체 — 마크업 · CSS · 로직
manifest.webmanifest    PWA 매니페스트
sw.js                   서비스 워커 (셸 캐시, 고칠 때 CACHE 값을 올린다)
icon.svg, icon-*.png    아이콘
docs/design-brief.md    UI 리파인 브리프 (요구사항 원문)
docs/design-decisions.md 무엇을 왜 바꿨는지
```

## 데이터

기록은 브라우저 `localStorage`에 남는다. 서버도 계정도 없다.

| 키 | 내용 |
|---|---|
| `gym5:sessions` | 세션 배열 — 날짜 · Day · 종목별 세트 `{무게, 횟수, 완료}` (최근 300개) |
| `gym5:excl` | 추천에서 제외한 종목 이름 배열 |

기록은 **종목 이름**으로 저장된다. 루틴이 다시 짜여도, 종목을 껐다 켜도 이전 기록과 증량 이력이 이어진다.

### 백업

브라우저 데이터를 지우거나 폰을 바꾸면 기록이 그대로 사라진다. 처방은 과거 기록에서 나오므로
잃으면 앱이 처음으로 돌아간다. **목록 탭 하단 → 데이터**에서 파일로 빼고 넣을 수 있다.

- **내보내기** — `workout-YYYY-MM-DD.json` 로 저장. 세션 전체와 제외 목록이 들어간다
- **가져오기** — 같은 `날짜 + Day`는 가져온 것으로 덮어쓰고 나머지는 합친다.
  같은 파일을 두 번 넣어도 중복되지 않으므로, 폰 두 대를 오갈 때도 그대로 쓸 수 있다

## 구조

세로 flex 3단 고정. 헤더와 하단 독은 고정, 가운데만 스크롤한다.
상태가 바뀌면 `render()`가 `innerHTML`을 통째로 갈아끼우므로, 진입 애니메이션 없이
CSS transition 수준의 마이크로 인터랙션만 쓴다.

탭은 네 개다.

- **오늘** — 그날 세션. 진행 중인 종목 하나만 펼치고, 끝난 것은 한 줄로 접는다
- **진행** — 최근 7일 부위별 볼륨을 목표 눈금선과 비교
- **기록** — 8주 볼륨 추이와 세션 로그
- **목록** — 62개 종목 라이브러리. 끄면 그 종목이 추천에서 빠지고 루틴이 다시 짜인다

## 처방 규칙

목표는 근비대 + 체지방(리컴프) 고정이다.

- 컴파운드 4세트 6–10회 / 휴식 120초, 고립 3세트 10–15회 / 휴식 60초
- 마지막 세션에서 **모든 워킹 세트가 목표 상한을 채웠으면** 증량 단위만큼 올린다
- 3세션 연속 최고 볼륨을 못 넘기면 **최고 시점 무게의 −10%로 디로드**
- 그 외에는 무게 유지, 목표 횟수 +1

주간 볼륨 목표는 두 단계다. 기록이 4주 미만이면 프로그램이 처방한 볼륨의 95~110%,
4주가 쌓이면 같은 부위 직전 4주 평균에서 +N%가 목표 구간이 되고 훈련 주차가 늘수록 좁아진다.
부위 집계는 주동근 1.0배, 컴파운드의 보조근(벤치 → 삼두·어깨)은 0.5배로 잡는다.
